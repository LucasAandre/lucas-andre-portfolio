
# Lucas André | Portfólio Profissional

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, formação acadêmica, habilidades técnicas, certificações e projetos de desenvolvimento de software.

## Sobre mim

Sou Engenheiro Eletricista e estudante de Análise e Desenvolvimento de Sistemas, com experiência em gestão de produtos, análise de indicadores e processos.

Atualmente, estou direcionando minha carreira para a Engenharia de Software, com foco em desenvolvimento back-end, especialmente utilizando Python e Java.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- Font Awesome

## Funcionalidades

- Interface responsiva
- Alternância entre português e inglês
- Persistência da preferência de idioma com localStorage
- Navegação entre seções
- Animações durante a rolagem
- Apresentação de projetos e certificações
- Links para redes profissionais
- Download do currículo

## Estrutura do projeto

- `index.html` — Estrutura da página
- `css/style.css` — Estilização e responsividade
- `js/script.js` — Interatividade e tradução
- `assets/` — Imagens, ícones e documentos

## Como executar

1. Clone o repositório.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
